# 2026-09-05 Journal 搜索与高级筛选

## 功能范围

- Journal 新增关键词搜索，可查找 Symbol、Setup、方向、Session、情绪、计划、备注、复盘、错误标签和 SOP 快照文字。
- 关键词忽略大小写、重音符号和多余空格；多个关键词必须同时匹配，减少无关结果。
- 高级筛选包含交易日期、Session、结果、等级、情绪、账户、Setup 和规则状态；顶部可直接切换进行中 / 已平仓。
- 账户默认保持“当前账户”，不会改变既有数据范围；用户可临时查看当前 SOP 的所有账户或指定账户，不会改变顶部工作区或写入状态。
- 同一筛选结果同时用于 SOP 时间线、进行中卡片、桌面表格和手机卡片。无结果时显示可恢复的空状态，Clear 一次清除全部条件。

## 兼容性与数据边界

- 筛选只读取内存中的当前用户资料，不调用 `saveState()`，不修改交易，也不产生 Firestore 写入。
- 原有当前 SOP / 当前账户范围、Setup 和规则筛选、交易排序及详情操作保持不变。
- 筛选核心位于 `journalFilterCore.js`，作为纯函数单独测试；文件已加入 Hosting 白名单和 Service Worker v206 缓存。

## 验证

- 纯筛选测试覆盖关键词、组合条件、日期边界、旧 Session / 规则值、账户范围、空输入和不修改原数组。
- 浏览器使用合成交易验证搜索同时更新 Timeline 与 Table，组合筛选命中正确记录，All accounts 能显示另一账户记录。
- 390px 手机宽度检查无页面级横向溢出。
- 完整 `npm test`、Firestore 规则模拟器、Hosting 白名单构建和差异格式检查在发布前执行。
